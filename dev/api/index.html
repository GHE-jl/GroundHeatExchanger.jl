By topic

Temporal superposition functions

  • convolution, convolutionf — stationary FFT convolution
  • impulse_func — incremental load function
  • convolution_ns, convolution_ns! — non-stationary convolution
  • impulse_func_ns — per-state incremental load matrix
  • state_indices, state_vector — operating-state bookkeeping

Fluid temperatures

  • fluid_temperature — mean fluid temperature
  • outlet_temperature, inlet_temperature — ends of the loop
  • outlet_transfer_function — complete short-/long-term outlet (EWT) transfer function

Short-term ANN model

  • short_term_response — ANN-based short-term outlet transfer function
  • short_term_nodes — raw ANN transfer function on its native time nodes (the building block behind short_term_response and outlet_transfer_function)
  • AbstractANN — model tag selecting which trained network to evaluate
    • DeepANN — Pasquier & Marcotte (2020); wider validity ranges, 95 nodes, 21-day horizon; the default for outlet_transfer_function
    • PublishedANN — Pasquier, Zarrella & Labib (2018); 85 nodes, 7-day horizon

Ground response and compression

  • ground_response — g-function interface, re-exported from GroundResponse.jl; compression via its interp keyword
  • pchip_interpolation — shape-preserving reconstruction

Utility functions

  • ground_load_profile — synthetic annual load
  • GHE — example parameter set
